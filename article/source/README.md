# Source and transcription record

The original is [arXiv:2412.03718v2](https://arxiv.org/html/2412.03718v2), dated 20 February 2025, licensed CC BY 4.0. The preserved HTML is `paper-v2.html`; its SHA256 is recorded in the conversion and fidelity reports. The original PDF is available at https://arxiv.org/pdf/2412.03718v2.

- `assets-manifest.json` maps all 13 unmodified local image assets to the 12 original figure numbers, source URLs and SHA256 hashes. It records visual checks against the PDF.
- `conversion-manifest.json` maps original source IDs to marked MyST blocks and documents the formatting transformations and added panel positions.
- `independent-inventory.json` records the source contents independently of the converter, including every table cell.
- `fidelity-report.json` compares the original HTML directly with the main paper and appendix: words, inline TeX, table cells, display equations, captions, references and links.
- `render-audit.json` checks the built MyST page structure, caption placement, images and math rendering.

These records concern the original paper transcription. The independently computed local experiment is documented separately in `supplements.md` and the Dash project's provenance files. The source text and images retain the original authorship; interactive companions and reading guidance are additions to this edition.
